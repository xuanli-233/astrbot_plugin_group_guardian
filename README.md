# QQ群智能守护者（精简版）

![version](https://img.shields.io/badge/dynamic/json?url=https://raw.githubusercontent.com/xuanli-233/astrbot_plugin_group_guardian/main/version.json&query=version&label=version&color=2563eb)

![license](https://img.shields.io/badge/license-MIT-green)
![astrbot](https://img.shields.io/badge/astrbot-%3E%3D4.24.2-cf6e34)

面向**多群统一管理**的 AstrBot 插件，适配 [LuckyLilliaBot](https://github.com/LLOneBot/LuckyLilliaBot)（OneBot 11 / aiocqhttp）。
基于 [zcj-ui/astrbot_plugin_group_guardian](https://github.com/zcj-ui/astrbot_plugin_group_guardian)（QQ群智能守护者 v2.8.11）二次开发：**停用了全部 AI 功能**，原有的内置审核规则默认关闭，新增了多群管理所需的功能。

> 当前版本：**v2.9.0** | 最低 AstrBot 版本：**>=4.24.2** | 协议端：LuckyLilliaBot（OneBot 11）

***

## 功能

| 功能 | 说明 |
| --- | --- |
| **关键词撤回 + 备份** | 消息命中你自己的关键词规则（包含 / 完全相同 / 正则）时，先把原消息以合并转发的形式备份到指定群，再撤回；可选同时禁言、群内提示 |
| **二维码 / 葵花码识别** | 两阶段：定位服务找出码 → 扩大框裁剪 → 解码服务解出内容 → 按正则过滤，命中即撤回并转发；一张图多个码时命中即停 |
| **跨群踢人 / 踢黑** | 一次在所有管理的群踢出一批人，可同时 QQ 拉黑（拒绝再次加群）并加入插件黑名单；拉黑必须填写原因 |
| **自动拉黑与拦截** | 退群自动拉黑（默认关）、黑名单用户加群申请自动拒绝、被邀请入群即踢、发言即踢 |
| **实时日志** | WebUI 实时查看近期消息的处理进度（检查关键词 → 下载 / 定位 / 解码 → 结果与耗时）；只存内存，页面在前台时才增量轮询 |
| **退群撤回** | 成员主动退群 / 被踢出后，自动撤回他最近 N 条、最近 M 分钟内的消息（两个条件可组合，默认关） |
| **重复成员检测** | 找出同时在多个群里的 QQ 号，可只保留一个群、全部踢出或忽略 |
| **批量公告 / 待办公告** | 勾选多个群一次发布群公告；「待办公告」= 置顶 + 需群成员确认 + 弹窗（LuckyLilliaBot 无群待办接口），可查看各群确认人数 |
| **群名后缀 / 倒计时** | 批量改群名后缀（立即或定时），群名倒计时每天自动更新（如「｜距考试 30 天」） |
| **群成员本地缓存** | 群列表与成员缓存到本地 SQLite，接口调用排队限流，进退群等通知实时更新缓存 |
| **操作记录** | 插件执行的每个写操作都有记录：时间、来源（指令 / WebUI / 自动）、操作人、群、对象、原因、结果 |
| **原有群管指令** | 禁言、解禁、踢人、全体禁言、名片、头衔、公告、群文件、精华、设置管理员、改群名等，全部保留，**默认关闭**，在「设置 → 功能开关」里按需打开（不影响上面的全群踢人、批量公告、群名任务等新功能） |

默认**关闭**：原有群管指令、AI 审核（已强制停用）、防刷屏、内置脏话 / 广告规则、外置词库、组合消息检测、Base 解码、QQ 收藏撤回、名片监控、入群审核等，需要时在设置里打开。详细的功能地图、开关与代码位置见 [FEATURES.md](FEATURES.md)。

## 安装

完整的部署步骤（AstrBot、连接 LuckyLilliaBot、安装插件、首次配置、识别服务、验证与更新）见 **[DEPLOY.md](DEPLOY.md)**。简要步骤：

1. 把本仓库放到 AstrBot 的插件目录：

   ```bash
   cd AstrBot/data/plugins
   git clone https://github.com/xuanli-233/astrbot_plugin_group_guardian.git
   ```

2. 安装依赖（AstrBot 通常会自动安装）：`pyahocorasick`、`opencv-python-headless`、`numpy`、`Pillow`。
3. 重启 AstrBot，在插件管理里打开本插件的管理页面，先在「设置」里**同意免责声明**。

> 本插件的识别名仍是 `astrbot_plugin_group_guardian`。如果之前装过原版，配置、黑名单与日志会保留，但**原版里已保存的配置不会因为本版的默认值改变而变化**，需要的话在设置里手动关闭不需要的功能。请不要再用插件市场「更新」原版，否则会被原版覆盖。

## 快速上手

管理页面左侧导航的「常用功能」：

| 页面 | 用途 |
| --- | --- |
| 关键词与识别 | 添加自己的关键词规则并测试；设置备份群与命中后的处理；配置二维码 / 葵花码识别服务、测试连接、上传测试图片 |
| 批量公告 | 勾选群发布群公告 / 待办公告，查看待办确认情况 |
| 群名任务 | 各群群名一览，改后缀、定时改名、设置倒计时 |
| 踢人与黑名单 | 跨群踢人 / 踢出并拉黑、自动拉黑开关、插件黑名单（含拉黑原因） |
| 重复成员 | 同时在多个群的人，只保留一个群 / 全部踢出 / 忽略 |
| 操作记录 | 所有操作，可按操作、来源、QQ 号 / 群号 / 原因筛选 |
| 群成员缓存 | 缓存状态与刷新、有效期与接口间隔设置、查某个 QQ 号在哪些群 |
| 违规记录 / 设置 | 撤回日志；全部开关、名单管理 |

插件自带的规则库在「更多（内置功能，默认关闭）→ 内置规则库」，与自己的关键词规则互不影响。

建议的上手顺序：

1. 设置里同意免责声明，在「名单管理」添加插件管理员（AstrBot 全局管理员会自动同步）。
2. 「关键词与识别」：选择**备份群**（机器人需在群内），添加几条关键词规则，用测试框确认命中效果。
3. 需要识别二维码 / 葵花码时：填写定位服务、API Key、解码服务地址 →「测试连接」→「上传测试图片」确认效果 → 打开开关。
4. 「群成员缓存」：点「全部刷新」建立缓存，之后跨群操作与重复成员检测都依赖它。

## 群内指令

需要「群操作权限」：WebUI 手动设置的插件管理员 / 群超管，或该群群主。默认开启「严格权限」，QQ 群管理员不会自动获得权限，需在 WebUI 单独设置（「设置」里可关闭严格权限）；标注「仅插件管理员」的跨群指令只有插件管理员能用。

### 新增指令

| 指令 | 作用 |
| --- | --- |
| `/全群踢人 QQ1 QQ2 … [原因：xxx]` | 在所有管理的群踢出这些人（仅插件管理员） |
| `/全群踢黑 QQ1 QQ2 … 原因：xxx` | 所有群踢出并 QQ 拉黑，同时加入插件黑名单（仅插件管理员） |
| `/批量踢黑 QQ1 QQ2 … [原因：xxx]` | 只在当前群踢出并 QQ 拉黑 |
| `/全群公告 [群号,群号] [-置顶] [-确认] [-新人] [-弹窗] 内容` | 批量发群公告，消息带图片时第一张作为配图（仅插件管理员） |
| `/全群待办 [群号,群号] 内容` | 批量发待办公告（置顶 + 需确认 + 弹窗，仅插件管理员） |
| `/确认发布` · `/取消发布` | 上面两条指令先回预览，确认后才发出（5 分钟内有效） |
| `/待办确认情况` | 最近一次待办公告在各群的确认人数 |
| `/群名后缀 <后缀> [群号,群号]` | 批量改群名后缀；`清除` 去掉后缀；`定时 YYYY-MM-DD HH:MM` 到点再改（仅插件管理员） |
| `/群名倒计时 YYYY-MM-DD ｜距考试{days}天 [群号,群号]` | 群名倒计时；`列表` / `停止` / `立即更新`（仅插件管理员） |

QQ 号可以空格分隔，也可以 @；原因写在「原因：」或「#」后面，原因里的数字不会被当成 QQ 号。不写群号时作用于所有管理的群（备份群除外）。

### 原有指令

`/禁言` `/解禁` `/踢人` `/批量禁言` `/批量踢人` `/全体禁言` `/撤回最新消息` `/批量撤回` `/回复撤回` `/设置名片` `/头衔` `/设置管理` `/取消管理` `/群名` `/加群方式` `/发公告` `/删公告` `/公告列表` `/文件列表` `/删文件` `/设精华` `/取消精华` `/成员列表` `/搜索成员` `/禁言列表` `/群统计` `/字数统计` `/自动审核` `/添加违禁词` `/删除违禁词` `/查看违禁词` `/设置管理插件` `/群管理授权` `/移除群管权限` `/恢复群管权限`

每条指令对应的功能开关见 [FEATURES.md](FEATURES.md) 第三节。

## 二维码 / 葵花码识别服务

识别依赖两个自行部署的本地服务：

| 服务 | 作用 | 文档 |
| --- | --- | --- |
| 定位服务（YuNet） | 上传整图，返回各类码的位置框；需要 `X-API-Key` | [service_api/定位服务API.md](service_api/定位服务API.md) |
| 解码服务 | 上传裁剪图，返回码类型（`QR_CODE` / `WX_CODE`）与内容 | [service_api/解码服务API.md](service_api/解码服务API.md) |

流程：下载图片 → 定位（超限图片先缩小）→ 取葵花码 / 二维码的框，向四周扩大 20%（可调）→ 纠正方向后裁剪 → 逐个解码 → 按「码内容正则规则」匹配，命中即停并撤回、转发。两个服务都按串行设计，插件对每个服务同时只发一个请求，`503` 时有限次重试；同一张图 10 分钟内不重复识别；服务不可用时放行并记日志，不会误撤回。

API Key 只保存在插件配置里，管理页面不回显，操作记录里只记「已设置」。也可以改用单个 HTTP 服务或插件目录下的 Python 文件接入，见 [examples/wxcode_recognizer_example.py](examples/wxcode_recognizer_example.py)。图片文字识别（OCR）可接 LuckyLilliaBot 自带的 `ocr_image` 或自己的服务，识别出的文字按关键词规则过滤（默认关闭）。

## 数据与记录

数据保存在 AstrBot 分配的插件数据目录（`data/plugin_data/astrbot_plugin_group_guardian/`）下的 `group_guardian.db`：

| 内容 | 说明 |
| --- | --- |
| 审核日志 | 撤回 / 备份记录，WebUI「违规记录」 |
| 操作记录 | `op_logs`，保留最近 10 万条 |
| 黑名单原因 | `blacklist_meta`：原因、来源、操作人、时间 |
| 群成员缓存 | `dir_groups` / `dir_members`，默认群列表 1 小时、成员 6 小时过期 |
| 群名任务、待办记录、重复成员忽略名单 | `meta` 表 |

插件配置（含识别服务 API Key）由 AstrBot 保存在其配置目录，不在本仓库中。

## 故障排查

| 现象 | 检查 |
| --- | --- |
| 指令提示无权限 | 发送者是否为插件管理员 / 群超管 / 群主；群管理员默认无权限（严格权限），需在 WebUI 设置；跨群指令只允许插件管理员 |
| 命中关键词但没撤回 | 机器人在该群是否为管理员；「自动审核」开关与本群的多群配置；看「操作记录」里的结果 |
| 没有备份到备份群 | 是否选择了备份群、机器人是否在该群；备份群本身不参与审核 |
| 识别服务不工作 | 「关键词与识别」→「测试连接」；API Key 是否填写；用「上传测试图片」查看每一步结果 |
| 跨群踢人漏掉了刚进群的人 | 勾选「执行前刷新成员缓存」，或在「群成员缓存」里刷新该群 |
| 群名修改失败 | 机器人需为群管理员；QQ 每次改群名都会在群里显示系统提示，无法屏蔽 |
| 群待办 | LuckyLilliaBot 没有群待办接口，本插件用置顶 + 需确认的群公告替代 |
